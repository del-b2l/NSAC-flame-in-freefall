# Scope

Locked on Friday 13 November at 8 pm. Changes after that need the whole team to agree.

## What we build

1. **Habitat picker, with the ranking rule on screen.** The user picks one of five habitats (Earth, Space station, Moon base, Rover, Spacesuit). The list of tests re-sorts. The rule from `ranking_rule.md` appears on screen.
2. **Prevent / Detect / Put out tabs.** Each tab lists the NASA experiments in that group:
   - Prevent: BASS, BASS-II, Saffire, BRE
   - Detect: SAME, SAME-R, DAFT
   - Put out: FLEX
3. **The 981-second card.** One fact from the Saffire VI presentation, with its source link.
4. **Honest safety table.** Each cell says one of three things: "Tested" (with a link to the NASA result), "Rule" (NASA's pass/fail rule), or empty. We never write a threshold that NASA did not publish.

## Also in the repo, but not shown to users

- Sample data and the official data from the challenge's Resources tab
- The Earth-use strip (water-mist extinguishers, smoke detectors, firefighter gear), if time allows on Saturday

## Out of scope

- RAG or AI-generated answers (the `rag/` folder stays as a placeholder)
- Login, accounts, or saving results
- Any data from rocket engines or propellants (the challenge excludes them)
- Partial-gravity data (none is available in the database yet)
- Mobile layout. Target is a laptop and a projector.
