# Data report

This page says what data the app uses, where each number comes from, and what we left out.
All tables below are generated by `data/scripts/build_report.py` from the processed files and
NASA's own metadata, so they always match the data the app ships.

## How much data NASA holds

NASA's metadata gives an archive size (`totalFileSize`) for each investigation. For the 24 kept investigations it adds up to **13.50 TB** (13,496,771,103,733 bytes). That is NASA's stated size of everything archived on PSI, not what we downloaded. We downloaded only the experimental summary tables, 211.12 kB in total for the kept investigations, plus each investigation's metadata. The per-investigation figure is in the table below.

## Investigations dropped

The PSI search is a text match on "combustion", so it also returns investigations from other research areas. `fetch_psi.py` lists these under `skipped` in the manifest and does not download them:

- **PSI-108** (Surface Tension Driven Convection Experiment-1): NASA files it under "Fluid Physics", not "Combustion Science".
- **PSI-181** (Structure and Properties of Pb-Sn and Pb-free Sn-Ag-Cu Solders Produced in Terrestrial vs. Microgravity Environments under Extremes of Elevated and Cryo Temperatures): NASA files it under "Materials Science", not "Combustion Science".

## Rules we followed

Nothing is guessed. A value is filled only when a NASA table states it; anything missing is null, and rows without both oxygen and pressure are left out rather than filled in. Raw files are never edited: the build scripts in `data/scripts/` read them, convert units, and write the processed files, and the tests in `data/tests/` check the output against the raw rows. Every PSI record keeps every original column under its NASA header and links to its PSI investigation page; the five Saffire IV-VI records link to the NTRS paper they were typed from.
